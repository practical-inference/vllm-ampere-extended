# Support

| Topic | Where |
|---|---|
| Bug in a build published here (regression between tags, wheel/install problem, Ampere-specific behavior) | [Open an issue](https://github.com/practical-inference/vllm-ampere-extended/issues/new/choose) |
| vLLM feature requests, model support, general vLLM bugs | [vllm-project/vllm issues](https://github.com/vllm-project/vllm/issues) |
| General vLLM questions and usage help | [vLLM user forum](https://discuss.vllm.ai) |
| Security vulnerabilities | [Private security advisory](https://github.com/practical-inference/vllm-ampere-extended/security/advisories/new) — see [SECURITY.md](SECURITY.md) |

Before opening a bug here, please check whether it reproduces on an upstream
vLLM release — if it does, it belongs upstream and will be fixed faster there.
The bug report template includes this check.
